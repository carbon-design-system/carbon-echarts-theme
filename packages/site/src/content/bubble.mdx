# Bubble Charts

Bubble charts extend scatter plots with a third dimension: circle size. Each data point is plotted at an (x, y) position with a radius proportional to a third variable, making it possible to visualize three quantitative dimensions simultaneously.

ECharts renders bubble charts using the `scatter` series type with a `symbolSize` function that scales the radius from the data.

See the [Carbon Charts Bubble documentation](https://charts.carbondesignsystem.com/bubble) for full API options and framework examples.
