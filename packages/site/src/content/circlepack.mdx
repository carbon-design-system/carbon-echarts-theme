# Circle Pack Charts

Circle pack charts display hierarchical data as a set of nested circles, where the area of each circle is proportional to its value. They are useful for visualizing part-to-whole relationships across multiple levels of a hierarchy.

## ECharts status

ECharts has no native packed-circle layout. Use [Carbon Charts CirclepackChart](https://charts.carbondesignsystem.com/circlepack) for this visualization.

**Post-MVP option:** evaluate `d3-hierarchy` pack layout pre-processor feeding an ECharts custom series.
