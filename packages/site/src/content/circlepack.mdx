# Circle Pack Charts

Circle pack charts display hierarchical data as a set of nested circles, where the area of each circle is proportional to its value. They are useful for visualizing part-to-whole relationships across multiple levels of a hierarchy.

ECharts does not include a native circle pack chart type. This chart is available in Carbon Charts — see the link below for a full interactive example.

See the [Carbon Charts Circle pack documentation](https://charts.carbondesignsystem.com/circlepack) for full API options and framework examples.
