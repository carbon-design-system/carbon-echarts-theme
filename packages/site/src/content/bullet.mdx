## Usage

Bullet charts are a compact alternative to gauges for showing a primary measure against a target and qualitative ranges (poor / satisfactory / good). They were designed by Stephen Few to replace dashboard gauges.

**When to use:**

- Showing performance against a target in limited space
- Comparing multiple KPIs in a compact dashboard layout
- When qualitative background ranges (red/yellow/green) add context

## Variants

- **Horizontal** — default; multiple bullets stack vertically.
- **Vertical** — rotated 90°; less common.

## Color

- Background range bands: alert palette (red → yellow → green, light to dark).
- Actual value bar: first categorical color.
- Target marker: `$text-primary` token.

## ECharts status

No direct ECharts equivalent. Use [Carbon Charts BulletChart](https://charts.carbondesignsystem.com/bullet) for this visualization.

**Optional workaround:** implement via `bar` + `markLine` (target marker) + `markArea` (range bands).
