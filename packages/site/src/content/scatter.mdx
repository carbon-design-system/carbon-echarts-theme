title: Scatter & Bubble chart
---

## Usage

Scatter charts show the relationship (correlation) between two continuous variables. Each point represents one observation. Bubble charts add a third dimension by encoding a numeric value in the circle's size.

**When to use:**

- Exploring correlation or distribution between two variables
- Identifying clusters, outliers, or trends in a dataset
- Bubble: when a third continuous variable adds meaningful context

**When not to use:**

- Categorical comparisons (use a bar chart)
- Fewer than ~10 data points (individual bars or a table is clearer)

## Color

- Use a **single categorical color** for a single series.
- Use the **categorical palette** when plotting multiple groups.

## Accessibility

- Always provide tooltips with exact values.
- Avoid relying on point size alone to convey meaning — include the value in the tooltip.

## ECharts implementation notes

Bubble charts use the `scatter` series type. Encode the third dimension as `symbolSize` via a callback: `symbolSize: (data) => Math.sqrt(data[2]) * 5`. The `createBubbleOptions` preset handles this automatically.
