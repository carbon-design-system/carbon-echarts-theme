# Pie Charts

Pie charts display part-to-whole relationships as proportional slices of a circle. Each slice represents a category's share of the total, making them ideal for showing relative proportions at a glance.

Use pie charts when you have a small number of categories (ideally fewer than six) and want to emphasize how each part contributes to the whole.

See the [Carbon Charts Pie documentation](https://charts.carbondesignsystem.com/pie) for full API options and framework examples.
