## Usage

Alluvial (Sankey) diagrams show flows between nodes. The width of each flow band is proportional to the quantity it represents. Use them to visualize data movement, redistribution, or transformation through a system.

**When to use:**

- Visualizing flows between two or more stages (e.g., user journeys, energy flows)
- Showing the redistribution of a total across categories
- Source-to-destination relationships

**When not to use:**

- Circular flows (use a chord diagram)
- More than ~8 nodes per column (becomes unreadable)

## Color

Assign colors by source node using the categorical palette.

## ECharts implementation notes

ECharts `sankey` series accepts `nodes` (name array) and `links` (`{source, target, value}` array). `createAlluvialOptions` infers nodes from the link list automatically. A tabular adapter (`createAlluvialOptionsFromTabular`) converts `{source, target, value}` rows from a flat data array.
