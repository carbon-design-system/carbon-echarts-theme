# Meter Charts

Meter charts display progress toward a known maximum on a linear scale. They are commonly used for utilization, quota, or capacity indicators — anywhere a value needs to be shown in context of a total.

ECharts implements the meter using a horizontal bar series styled to match the Carbon token palette.

See the [Carbon Charts Meter documentation](https://charts.carbondesignsystem.com/meter) for full API options and framework examples.
