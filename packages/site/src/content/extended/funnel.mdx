## Usage

Funnel charts display stages in a sequential process and the attrition or conversion at each stage. The width of each band is proportional to the value at that stage.

**When to use:**
- Showing conversion rates through a multi-step process (e.g., sales funnel, user onboarding)
- Comparing values at each stage of a pipeline
- Highlighting drop-off between stages

**When not to use:**
- Non-sequential data (use a bar chart)
- More than 8 stages

## ECharts implementation notes

This chart type has no Carbon Charts equivalent. ECharts `funnel` series with `sort: 'descending'` and `gap: 2` matches the standard funnel appearance. All Carbon theme tokens apply.
