## Usage

Sunburst charts display hierarchical data as a series of concentric rings. Each ring represents a level of the hierarchy. Slice angles are proportional to value, similar to a pie chart.

**When to use:**
- Showing hierarchical part-to-whole relationships
- Exploring multi-level drill-down data
- When a treemap would benefit from radial organization

**When not to use:**
- More than 3–4 hierarchy levels (outer rings become too thin)
- Precise value comparison

## ECharts implementation notes

This chart type has no Carbon Charts equivalent. It uses ECharts `sunburst` series with `radius` and `sort` config. All Carbon theme tokens apply: fonts, colors, background.
