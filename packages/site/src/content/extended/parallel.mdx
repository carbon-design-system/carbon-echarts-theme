## Usage

Parallel coordinate charts display multivariate data across multiple vertical axes arranged in parallel. Each line represents one data record, connecting its values across all axes. They are powerful for spotting patterns and clusters in high-dimensional datasets.

**When to use:**
- Exploring relationships across 4–10 numeric dimensions
- Identifying clusters or outliers in multivariate data
- Comparing profiles of multiple entities simultaneously

**When not to use:**
- Fewer than 4 dimensions (use a scatter chart)
- More than ~200 data records (lines overlap too much)

## ECharts implementation notes

This chart type has no Carbon Charts equivalent. ECharts `parallel` coordinate system with `parallelAxis` definitions. Filter interactions via `brush` component are available. All Carbon theme tokens apply.
